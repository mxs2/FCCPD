# Respostas

( X ) Race Condition - Presente no incremento do contador.
( X ) Deadlock - Presente na inversão de dependência entre recursoA e recursoB.
( X ) Starvation - Presente na Tarefa3, onde o busy-wait monopoliza a CPU e prejudica as outras threads.
( X ) Livelock - A abordagem de tryLock em loop infinito da Tarefa3 também é um exemplo clássico de padrão que leva ao Livelock se múltiplas threads estiverem no mesmo estado, respondendo à disputa de forma cíclica sem progresso real.
